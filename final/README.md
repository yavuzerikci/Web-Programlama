# Hava Durumu Final (React + API)

## 1) Projeyi çalıştırma (VS Code)
1. Bu projeyi bilgisayarına indir (Code > Download ZIP) ya da klonla.
2. VS Code ile proje klasörünü aç.
3. Terminali aç (Terminal > New Terminal).
4. Terminalde proje klasörüne gir:
   - Klasör adın: `hava-durumu-final`
5. Aşağıdaki komutları sırayla çalıştır:
   - `npm install`
   - `npm run dev`
6. Tarayıcıda şu linke gir:
   - `http://localhost:5173/`
